# Decision records

One short file per decision that shapes the architecture or rules out an
alternative for a reason a later reader would otherwise have to rediscover.
Number them in order: `0001-short-title.md`. Never edit a decided record to
change its outcome; write a new one that supersedes it.

```markdown
# 0001. Short title

Status: proposed | accepted | superseded by 0007
Date: YYYY-MM-DD

## Context

What forces the decision: the problem, the constraints, what was observed.

## Decision

What we do, stated plainly.

## Consequences

What gets easier, what gets harder, and what we gave up.
```
